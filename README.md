# Ejercicios de JavaScript 🚀

Este repositorio contiene una colección de ejercicios básicos de programación resueltos con **JavaScript**. Es un espacio dedicado a la práctica de lógica de programación, operaciones matemáticas y manipulación de variables.

## 📋 Contenido de los ejercicios

Entre los ejercicios resueltos en este repositorio se incluyen:

* **Operaciones matemáticas básicas:** Cálculo de áreas, perímetros y porcentajes (IVA).
* **Conversión de datos:** Transformación de unidades de tiempo (horas/minutos a segundos).
* **Lógica y condicionales:** Comprobación de números pares e impares, y extracción de dígitos (decenas y unidades).
* **Algoritmos aplicados:** Calculadora de proporciones para recetas e intercambio de variables.

Dado que son scripts de JavaScript puro, tienes un par de opciones sencillas para probarlos:

1. **En el navegador:** Puedes copiar el código de cualquier archivo `.js` y pegarlo directamente en la consola de las herramientas de desarrollador de tu navegador (presionando `F12` o `Ctrl + Shift + I`).
